# Thilanga portfolio

Home and About sections. Run `node server.cjs` and open http://127.0.0.1:4173.

Static website files live in `dist/`. Edit identity and copy in `dist/index.html`, shared styling in `dist/styles.css`, floating navbar in `dist/navbar.css`, footer styling in `dist/footer.css`, and navigation/dialog/reveal behavior in `dist/script.js`.

The portrait is original generated cyber artwork, not a photo of the portfolio owner. Replace `dist/assets/cyber-portrait.png` when a personal photo is supplied. The name is an editable assumption. Real email and social profile URLs have not been supplied; the connect dialog explicitly marks these as coming soon.

About styling is isolated in `dist/about.css`. It follows the supplied three-column reference in Home's charcoal/orange palette, with Tools replacing Experience. The education copy and learning toolkit are editable draft content; no institution, dates, qualifications, or proficiency claims have been invented.

Add subsequent sections only after receiving their reference images. Preserve completed sections. Add actual navigation anchors when those sections exist; the observer automatically highlights them.
